# Аерокосмічна техніка та оборонні технології — КМАН

Статичний курс для GitHub Pages. 46 тематичних занять, вступ, 11 розділів і дослідницьке портфоліо.

## Публікація
Завантажте **вміст** цієї папки в корінь репозиторію. Settings → Pages → Deploy from a branch → main / root. Відкрийте адресу GitHub Pages.

## Функціональність
Кожне заняття має питання, програмний зміст, навчальну модель, поля гіпотези, порівняння, джерел, висновку та друк у PDF. Збереження — localStorage браузера. Без сервера й реєстрації.

## Важливе обмеження
Моделі спрощені, частина з них ілюструє математичні залежності, а не фізику конкретної техніки. Цей випуск є повним навігаційним каркасом з робочими вправами; спеціалізовані моделі для кожного заняття потребують подальшого предметного опрацювання.
